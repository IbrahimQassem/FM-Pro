# هدهد FM — قالب لقطات المتاجر

سلسلة من ست لقطات عربية، بهوية كحلية وسماوية قابلة للتغيير. واجهة التطبيق هي
العنصر الرئيسي؛ بدون إطار جهاز أو منظور مائل. جميع النصوص قابلة للتحرير، والخط
IBM Plex Sans Arabic مضمّن محليًا مع ترخيص OFL. لا يعتمد القالب على Firebase أو
خدمة خارجية، ولا يغير واجهة تطبيق Flutter.

## فتح الاستوديو

من مجلد القالب:

```sh
node server.mjs
```

افتح `http://127.0.0.1:4186` في المتصفح. يمكن تغيير المنفذ عبر
`SCREENSHOT_STUDIO_PORT`. يعمل الخادم على جهازك فقط. يتطلب Node.js 22 أو أحدث.

1. اختر إحدى اللقطات الست من الصور المصغرة.
2. عدّل العنوان والوصف والعبارة التمهيدية وارفع Screenshot حقيقيًا.
3. غيّر اسم التطبيق والشعار والألوان من الشريط الجانبي.
4. بدّل بين Apple وGoogle لمعاينة التكوين المخصص لكل نسبة.
5. «تصدير المقاسين» يحفظ 12 ملف PNG ولوحتي عرض في `exports/`.
6. «تنزيل اللقطة الحالية» ينزّل PNG واحدًا إلى المتصفح.

«حفظ الإعدادات» ينزّل ملف JSON يحتوي النصوص والألوان والصور المرفوعة؛ يمكن
استيراده لاستكمال العمل لاحقًا. التغييرات لا تُحفظ تلقائيًا عند إغلاق الصفحة.
لتغيير القالب الافتراضي بشكل دائم، عدّل `config.js` أو استبدل الملفات في
`assets/screenshots/`. زر «استخدام مساحة صورة فارغة» يزيل الصورة من اللقطة
المختارة ويُظهر موضع الإدراج. تُعاد كتابة ملفات التصدير السابقة عند تصدير السلسلة.

| حجم الملف | 1320 × 2868 px | 1080 × 1920 px |
| الاتجاه | عمودي | عمودي 9:16 |
| مساحة آمنة جانبية | نحو 108 px | 88 px |
| العنوان | سطران بحد أقصى، السطر الثاني بالتمييز | نفس النظام |
| لقطة التطبيق | صورة كاملة بنسبة أبعادها الأصلية | صورة كاملة بنسبة أبعادها الأصلية |
| التصدير | PNG بخلفية معتمة | PNG بخلفية معتمة |

الأبعاد حسب طلب التصميم، وليست شهادة قبول من المتجر. يُعاد تركيب كل مقاس مباشرة
بدقته الأصلية؛ لا تُمدد صورة Apple لتصبح Google. تصغر النصوص الطويلة ضمن حدود
مقروئية محددة، ويمنع التصدير إذا تجاوز النص مساحة العنوان أو الوصف. لا يُقص
محتوى لقطة التطبيق لملء المساحة؛ قد يظهر فراغ حولها بحسب نسبة الصورة المدخلة.

## مصدر الصور وحدود الاستخدام

- الشعار من `assets/images/branding/app_icon_1024.png` في المشروع.
- صور المثال من `build/review/continuation/after/*-ar-1.0x.png`؛ وهي لقطات
  واجهات Flutter ببيانات اختبارات، بدقة 430 × 932. لم تُنشأ واجهة تطبيق وهمية.
- هذه الصور منخفضة الدقة للمعاينة وليست لقطات إصدار نهائية. استبدلها بلقطات
  حديثة عالية الدقة من الجهاز/المحاكي، وبصور مناسبة لكل منصة قبل رفعها إلى المتجر.
- العناوين نصوص تسويقية قابلة للاستبدال حسب طلب القالب؛ راجع أي ادعاء مثل
  «أسرع» مقابل سلوك الإصدار النهائي قبل النشر.
- يمكنك التحول إلى لوحة عنابية مستوحاة من هوية التطبيق بزر واحد؛ الافتراضي
  كحلي/سماوي حسب الطلب، دون إعادة تلوين صور التطبيق نفسها.
- مصدر الخط: [Google Fonts / IBM Plex Sans Arabic](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic).
  الترخيص المرفق: `assets/fonts/OFL.txt`.

## الملفات

`index.html` و`studio.css`: محرر محلي عربي. `studio.js`: التكوين والرسم والتصدير.
`config.js`: المحتوى الافتراضي. `server.mjs`: معاينة وحفظ محليان بدون اعتمادات.
`exports/`: الصور النهائية للقالب ولوحتا المعاينة. الأصل القابل للتحرير هو هذه
الملفات والإعدادات، أما PNG فهو نسخة مسطّحة للتسليم.

## التحقق — 2026-09-14

- فُحصت لوحتا السلسلة بصريًا، مع ترتيب اللقطات من اليمين إلى اليسار.
- اختُبرت المعاينة في عرض هاتف وعرض سطح مكتب، وتبديل Apple/Google.
- اختُبر تغيير العنوان، ورفع صورة بديلة من ملف محلي، وإزالة الصورة، وتبديل
  لوحتي الألوان، وتصدير السلسلة.
- يمكن إعادة التحقق من أبعاد ملفات PNG وغياب الشفافية بعد أي تصدير:

```sh
node verify-exports.mjs
```

ينتج `exports/manifest.json` بالأبعاد والحجم وبصمة SHA-256 لكل صورة. التحقق خاص
بأصول التصميم؛ لم يلزم بناء Flutter لأن كود التطبيق لم يتغير.
