# Definition of done

الميزة أو المرحلة مكتملة فقط عندما تتحقق البنود المناسبة التالية.

## الوظيفة

- معايير القبول قابلة للملاحظة وتعمل في النكهات المتأثرة.
- loading/content/empty/offline/error ممثلة دون قيم تقنية خام.
- سلوك الرجوع ودورة الحياة وprocess recreation محدد ومختبر حيث يلزم.

## مصدر الحقيقة

- لا يوجد model أو constant أو repository منافس دون قرار.
- العقود والخطة وسجل الدين محدثة ولا تتكرر الحالة في ملف آخر.
- الكود القديم المستبدل محذوف، أو seam المتبقي مسجل بمعيار إزالة.

## الجودة والأمان

- tests المناسبة نجحت وسجلت الأوامر والنتائج.
- لا سر أو log حساس أو permission غير مبرر.
- صلاحيات الكتابة مختبرة من جهة الخادم.
- UI ينجح مع RTL وTalkBack وخط 200% عند تغييره.

## التسليم

- `./tools/verify-governance.sh` ناجح.
- debug build ناجح للنُكهات المتأثرة.
- لا تحذير جديد متروك دون بند دين.
- المخاطر وما لم يُختبر مذكوران بوضوح.
