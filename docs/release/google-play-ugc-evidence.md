# قائمة أدلة Google Play — UGC وحذف الحساب

الحالة: بوابة إصدار

بيئة الالتقاط: Firebase Development وحسابات اختبار فقط

آخر تحديث: 2026-09-02

هذه القائمة تمنع إعادة تقديم وصف أو رابط لا يطابق المنتج الفعلي. لا تلتقط بريدًا
حقيقيًا أو UID أو محتوى حساسًا. تحفظ الصور/الفيديو خارج Git في مجلد الإصدار
المقيد وتؤرخ بتاريخ الالتقاط ورقم البناء.

## ترتيب النشر قبل الالتقاط

1. شغّل `comments:status:dry` ثم `comments:status:apply` على البيئة المستهدفة بعد
   مراجعة العدد، إذا كانت تحتوي تعليقات قديمة بلا حالة.
2. انشر `firestore.indexes.json` وانتظر اكتمال بناء الفهارس.
3. انشر `firestore.rules` ثم `functions/deleteAccountData`.
4. ابنِ وانشر `admin_web` الذي يحتوي `/community-guidelines` و
   `/account-deletion`.
5. ثبّت build التطبيق المطابق واستخدم حسابين مستمعين وحساب مشرف للاختبار.

كل خطوة نشر فعل خارجي مستقل يحتاج تفويضًا وrollback مناسبًا؛ لا تنفذها اختبارات
المستودع تلقائيًا.

## لقطات وفيديو UGC المطلوبة

| ID | الدليل | معايير النجاح |
|---|---|---|
| UGC-E01 | شروط المشاركة قبل أول تعليق | يظهر النص المحظور، الإشراف، وزر موافقة صريح؛ الإغلاق لا يفتح المحرر |
| UGC-E02 | قائمة إجراءات تعليق لمستخدم آخر | تظهر «الإبلاغ عن التعليق»، «الإبلاغ عن المستخدم»، و«حظر المستخدم» منفصلة |
| UGC-E03 | إرسال بلاغ تعليق وبلاغ مستخدم | سبب محدد، تفاصيل محدودة، ورسالة نجاح بلا كشف هوية المبلّغ |
| UGC-E04 | الحظر والتراجع | تختفي تعليقات المؤلف للمستخدم الحاظر فقط ويظهر إجراء تراجع |
| UGC-E05 | طابور المشرف | يظهر نوع الهدف والسبب والسياق وأزرار الرفض/الإخفاء/الإزالة/التعطيل |
| UGC-E06 | إخفاء تعليق | يختفي من حساب ضيف ومن طلب Firestore عام، ويسجل القرار في البلاغ |
| UGC-E07 | تعطيل حساب | تفشل محاولة تعليق أو كتابة شخصية لاحقة برسالة آمنة |

يفضل فيديو واحد قصير يبدأ بحساب المستمع وينتهي بقرار المشرف ثم تحديث شاشة
الضيف، إضافة إلى لقطات ثابتة واضحة لكل زر يطلبه نموذج المراجعة.

## أدلة حذف الحساب

| ID | الدليل | معايير النجاح |
|---|---|---|
| DEL-E01 | الحذف داخل التطبيق | كلمة مرور حالية + إقرار صريح + نجاح يعيد لحالة الضيف |
| DEL-E02 | الصفحة العامة | `/account-deletion` تفتح بلا تسجيل إداري وتوضح البيانات المحذوفة ونهائية الإجراء |
| DEL-E03 | حذف فعلي بحساب اختبار | يختفي Auth والملف والتعليقات والبيانات التابعة وتصح عدادات الحلقات |
| DEL-E04 | فشل المصادقة | رسالة عامة، الحساب والبيانات يبقيان، ولا يظهر Firebase code |
| DEL-E05 | شروط المجتمع | `/community-guidelines` متاحة علنًا وتطابق نص الموافقة داخل التطبيق |

الرابط المقترح لحقل حذف الحساب بعد النشر:

```text
https://hudhud-fm-admin-sanadev.web.app/account-deletion
```

ورابط شروط المشاركة:

```text
https://hudhud-fm-admin-sanadev.web.app/community-guidelines
```

استبدل hostname بدومين عام أنسب قبل Production إن توفر؛ لا تضع الرابط في Play
Console حتى ينجح اختبار نافذة خاصة وتعمل الدالة المنشورة.

## سجل الاعتماد

يسجل مالك الإصدار خارج Git: رقم البناء، commit، تاريخ الالتقاط، بيئة Firebase،
معرّفات الأدلة المكتملة، اسم الدور الذي راجعها، ونتيجة اختبار الروابط. أي تغيير
في شروط UGC أو المسارات أو قرارات الإدارة يبطل الأدلة السابقة ويتطلب إعادة
الالتقاط.
