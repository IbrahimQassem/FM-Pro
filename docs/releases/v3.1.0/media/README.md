## 2. Media Asset Details & Feature Mapping

### Poster 01 — Station Social Connectivity (`FEAT-STATION-SOCIAL-LINKS`)
* **Creative Concept**: 3D Acoustic Studio Glassmorphism with Floating Social Connectivity
* **Arabic Slogan**: «تواصل مباشر مع إذاعتك المفضلة»
* **Key Visuals**: Sleek smartphone displaying Station Details with interactive chips for Website, Facebook, Instagram, YouTube, X, and WhatsApp, accompanied by the Hoopoe mascot with studio headphones.
* **Specification Document**: [`../POSTERS/POSTER_01_STATION_SOCIAL_LINKS.md`](file:///Users/iq/AndroidStudioProjects/accelerate/hudhud_fm/docs/releases/v3.1.0/POSTERS/POSTER_01_STATION_SOCIAL_LINKS.md)

### Poster 02 — Super Admin Excel Export (`FEAT-SUPER-ADMIN-EXCEL-EXPORT`)
* **Creative Concept**: Luxury Executive Operations & 44-Column RTL Excel Governance
* **Arabic Slogan**: «إدارة متكاملة وتصدير فوري إلى Excel»
* **Key Visuals**: Modern laptop displaying Web Admin stations table, with floating holographic Excel spreadsheets, emerald `.xlsx` emblem, and golden Super Admin security badge.
* **Specification Document**: [`../POSTERS/POSTER_02_SUPER_ADMIN_EXCEL_EXPORT.md`](file:///Users/iq/AndroidStudioProjects/accelerate/hudhud_fm/docs/releases/v3.1.0/POSTERS/POSTER_02_SUPER_ADMIN_EXCEL_EXPORT.md)

### Poster 03 — Broadcast Engineering Telemetry (`FEAT-BROADCAST-TECH-SPECS`)
* **Creative Concept**: Radio Frequency Studio & FM Transmission Engineering
* **Arabic Slogan**: «رصد فني متقدم وهندسة بث دقيقة»
* **Key Visuals**: Radiating FM transmission tower, glowing audio spectrum, floating telemetry badges (`128 kbps • AAC+`, `92.5 MHz`, `5 kW Transmitter`, `RDS: SANAA FM`), and technician Hoopoe mascot.
* **Specification Document**: [`../POSTERS/POSTER_03_BROADCAST_TECHNICAL_SPECS.md`](file:///Users/iq/AndroidStudioProjects/accelerate/hudhud_fm/docs/releases/v3.1.0/POSTERS/POSTER_03_BROADCAST_TECHNICAL_SPECS.md)
