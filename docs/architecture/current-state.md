# Current-state baseline

التاريخ: 2026-08-26  
الغرض: خط أساس وصفي؛ العقود في `../contracts/` هي السلطة المعيارية.

## البناء

- وحدة واحدة `:app`، كود Java 8 وواجهات XML.
- Android Gradle Plugin 7.2.1 وGradle 7.6.3.
- `compileSdk` و`targetSdk` 34، و`minSdk` 21.
- البناء مثبت على JDK 17 عبر `.java-version` وCI، ويفشل على JDK 25 بسبب توافق
  toolchain الحالي.
- النكهات: `hudhud_fm`, `hudhudfm_google_play`, `internews`.
- نكهة `internews` لا تُبنى حاليًا لأن إعداد Google Services لا يحتوي client
  مطابقًا للحزمة `com.sanaadev.internews`؛ يتابعها TD-015.

## الحجم والاختبار

- بعد التنظيف الحالي: 150 ملف Java رئيسي و60 layout XML.
- ستة اختبارات unit لقرارات Splash والوصول؛ لا تزال التغطية السلوكية العامة ضعيفة.
- Activities وFragments وAdapters تتصل بـFirebase مباشرة في مواضع متعددة.

## تدفقات المنتج الحالية

- Splash يجمع Remote Config وanonymous auth والتحديث وجلب المحطات قبل الدخول؛
  فشل auth أو انتهاء مهلة 3 ثوانٍ يواصل وضع المستمع، وفشل تحديث المحطات يستعيد
  القائمة المحلية بدل منع فتح التطبيق.
- الرئيسية تعرض الحساب والإعلان والمحطات والبرنامج والمشغل في مساحة واحدة.
- المشغل خدمة مخصصة مرتبطة مباشرة بزر واجهة.
- الإدارة تظهر ضمن قائمة المستمع بناءً على دور مخزن محليًا.
- إضافة البرنامج والحلقة تتم عبر Activities طويلة متعددة الخطوات.

## مخاطر مثبتة

- أزيل `key.properties` من التتبع الحالي، لكن السر التاريخي يحتاج تدويرًا وتقييمًا.
- أزيلت صلاحيات الهاتف والتخزين القديمة، ويطلب مسار التقاط الصورة `CAMERA`
  عند الحاجة فقط. يبقى `usesCleartextTraffic=true` حتى حصر مضيفي البث الفعليين
  القادمين من Firestore وتعريف استثناءات الشبكة الدنيا.
- أزيلت سجلات FCM/User/device الحساسة المرصودة، لكن يلزم استمرار فحص كل مسار معدل.
- أُصلح `FIRST_TIME_VERSION` واختُبر قرار التوجيه، بينما ما زال Splash يجمع
  مسؤوليات وعمليات شبكة كثيرة.
- قيم بيانات ناقصة قد تصل إلى UI كـ`null`.
- توجد اعتماديات قديمة؛ أزيل `latest.release` والمستودعات المكررة في خط الأساس.
- إعداد Firebase غير مكتمل لإحدى النكهات، لذلك لا تُعد مصفوفة النكهات سليمة بعد.

## تنظيف تم في هذا الأساس

حُذفت 12 ملفات Java كانت مكوّنة بالكامل من كود معلّق، ثم حُذف `UserHelper`
و`MyNotificationManager` و`ProfileImageHelper` و`Global` غير المستخدمين وملف
`shoutcasts.json` التجريبي وواجهة password المعلقة. التفصيل الأمني في TD-016
والتنظيف الأول في TD-001. Git يحتفظ بالتاريخ عند الحاجة.
