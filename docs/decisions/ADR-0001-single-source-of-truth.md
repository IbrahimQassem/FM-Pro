# ADR-0001: Single source of truth

الحالة: accepted  
التاريخ: 2026-08-26

## السياق

المشروع يملك كود legacy وتدفقات Firebase متعددة، وكان README غير صالح ولم توجد
عقود أو خطة محلية. نسخ الخطط بين مستودعات أو ملفات يجعل القرارات تتباعد.

## القرار

`FM-Pro` هو مصدر الحقيقة الوحيد للتطبيق الأصلي. يحدد `AGENTS.md` خريطة السلطة،
وتعيش العقود في `docs/contracts`، الحالة في خطة واحدة وسجل دين واحد، والقرارات
في ADRs. السلوك النهائي يثبته الكود والاختبارات داخل المستودع.

## النتائج

- لا يعتمد التنفيذ على مستودع أو تطبيق موازٍ.
- يجب تحديث العقد والكود معًا عند تغيير contract.
- التقارير المؤقتة واللقطات أدلة وليست سلطة.
- التكرار يزال وتستبدل النسخ بروابط.
