# هدهد إف إم — استوديو لقطات المتاجر

استوديو عربي/إنجليزي لتصميم ست لقطات تسرد تجربة هدهد الفعلية: اكتشاف الإذاعات،
البرامج، البث المباشر، المتابعة، الحساب، والبدء دون حساب.

الهوية مأخوذة من `lib/core/theme/app_colors.dart`: العنابي والوردي الهادئ والأبيض
الدافئ. الماسكوت الأصلي يظهر بجانب العنوان في لقطتي الترحيب، ولا يغطي واجهة
التطبيق. مصدره `assets/images/mascot/mascot_onboarding.webp` في جذر المشروع؛
نسخته المحلية ضمن هذا القالب لا تضيف شيئًا إلى حزمة Flutter.

## المعاينة

```sh
cd store-listing-generator/store-screenshots
node server.mjs
```

افتح `http://127.0.0.1:4186`. الخادم محلي فقط؛ يمكن تغيير المنفذ عبر
`SCREENSHOT_STUDIO_PORT`. لا توجد اعتمادات npm أو خدمات خارجية أثناء التشغيل.

1. اختر العربية أو English؛ يتغير اتجاه المحرر والنصوص إلى RTL أو LTR.
2. اختر داكن أو فاتح؛ تتغير ألوان التصميم والمحرر ولقطة التطبيق الفعلية.
3. اختر Apple App Store أو Google Play؛ يتغير المقاس والجهاز ولقطة المنصة.
4. اختر إحدى اللقطات الست، وعدّل النص أو ارفع صورة PNG/JPEG/WebP حتى 20 MB.
5. افتح «هوية السلسلة» لتعديل الشعار وألوان المظهر المختار.
6. نزّل اللقطة الحالية، أو صدّر جميع النسخ إلى `exports/`.

النصوص محفوظة بشكل مستقل لكل لغة. الألوان محفوظة بشكل مستقل لكل مظهر. رفع
صورة أو إزالتها يخص اللغة والمظهر والمنصة واللقطة المختارة فقط. تغيير المقاس
أو اللغة لا يفقد التعديلات.

## مصفوفة التسليم

| الخيار | القيم |
|---|---|
| اللغة | العربية `ar`، الإنجليزية `en` |
| المظهر | داكن `dark`، فاتح `light` |
| Apple App Store | 1320 × 2868 px، إطار iPhone 17 Pro |
| Google Play | 1080 × 1920 px، إطار Galaxy S26 Ultra |
| العدد | 6 × 2 × 2 × 2 = **48 لقطة PNG** + **8 لوحات عرض** |

كل مقاس يُرسم مباشرة بدقته الأصلية بخلفية معتمة. ترتيب لوحات العرض عربي RTL
وإنجليزي LTR. العناوين تُصغّر ضمن حد مقروء، ويظهر خطأ إذا تجاوز النص المساحة.

أسماء الملفات هي `{platform}-{locale}-{appearance}-{slide}.png`، باستثناء
العربية الداكنة التي تحتفظ بالأسماء السابقة مثل `apple-01-hero.png` لضمان
توافق الروابط القديمة. `exports/manifest.json` يحدد اللغة والمظهر والمنصة لكل ملف.
إعادة التصدير تستبدل ملفات التصميم السابقة.

## الحفظ والاستيراد

«حفظ الإعدادات» ينزّل JSON بالإصدار 2، يشمل اللغتين والمظهرين وجميع الصور
المرفوعة. لا يوجد حفظ تلقائي. يمكن استيراد الملفات القديمة من الإصدار 1:
تُحفظ نصوصها في العربية، وألوانها في الداكن، وصورها في خانات العربية الفاتحة.
تبقى بقية النسخ من الافتراضيات حتى تعديلها. `config.js` هو المصدر الافتراضي.

## مصدر اللقطات والأجهزة

- الصور داخل `assets/screenshots/{platform}-{locale}-{appearance}/` مرسومة من
  Widgets التطبيق الحالية باستخدام `test/review/screen_acceptance_test.dart`.
- الالتقاط بدقة 3×: Apple بحجم 1206 × 2619، وAndroid بحجم 1236 × 2673.
- يستخدم الاختبار بيانات تطوير وخط IBM Plex Sans Arabic بدل خطوط نظام الجهاز؛
  هذه ليست لقطات ملتقطة من أجهزة فعلية ولا اعتمادًا نهائيًا لرفع المتاجر.
- تبقى أسماء المحطات والبرامج العربية كما هي داخل واجهة التطبيق الإنجليزية،
  لأن محتوى الإذاعات نفسه عربي. أما عناصر الواجهة والنص التسويقي فمترجمة.
- أصول الأجهزة PNG فعلية مرخّصة، وليست رسومات تقريبية بالكود. مصدرها وحدود
  استخدامها ودقتها موثّقة في [assets/devices/README.md](assets/devices/README.md).
- أصول الإطار المجانية ارتفاعها 800px وتُكبّر داخل التصدير؛ تتوفر نسخ HD لدى
  المصدر إذا لزم تسليم أكثر حدة لحواف الجهاز.
- لا توجد ادعاءات غير مثبتة عن عدد الإذاعات أو المستمعين أو ضمان استقرار البث.

## إعادة التقاط واجهة التطبيق

من جذر `hudhud_fm`، لكل زوج `ios|android` و`light|dark`:

```sh
HUDHUD_REVIEW_FONT=store-listing-generator/store-screenshots/assets/fonts/IBMPlexSansArabic-Regular.ttf \
HUDHUD_REVIEW_STAGE=store-ios-light HUDHUD_REVIEW_THEME=light \
HUDHUD_REVIEW_PLATFORM=ios HUDHUD_REVIEW_PIXEL_RATIO=3 \
flutter test test/review/screen_acceptance_test.dart --plain-name '1.0x screen acceptance'
```

ينتج اللغتين تحت `build/review/continuation/store-ios-light/`. انسخ شاشات
`home`, `station`, `program`, `my-stations`, `account` إلى مجلد النسخة المطابق،
مع حذف اللاحقة `-ar-1.0x` أو `-en-1.0x` من اسم الصورة. القالب مستقل عن Firebase.

## التحقق

بعد التصدير:

```sh
node verify-exports.mjs
```

يفحص 48 صورة و8 لوحات: الأبعاد، PNG المعتم، اختلاف النسخ وبصمات SHA-256.
تُراجع أيضًا جميع اللوحات بصريًا، والتحرير، والاستيراد، وRTL/LTR، وعرض الهاتف.

`locales.js` لنصوص المحرر، `config.js` لمحتوى الحملة، `studio.js` للرسم والتصدير،
`index.html` و`studio.css` للمحرر، و`server.mjs` للمعاينة والحفظ المحليين.
